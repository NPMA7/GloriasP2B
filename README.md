# 🏀 Glorias Basketball — SMK Pasundan 2 Banjaran

Platform web resmi **Ekstrakurikuler Bola Basket SMK Pasundan 2 Banjaran (Glorias P2B)**.
Dibuat menggunakan **Next.js (App Router) + TypeScript + Tailwind CSS** dengan tema *Modern Athletic Dark Championship* yang siap di-deploy secara instan ke [Vercel](https://vercel.com).

---

## ✨ Fitur Utama
- 🏆 **High-Impact Hero & Live Stats**: Menampilkan slogan *"FORGED IN GLORY, PLAYED WITH PRIDE"*, counter kejuaraan, dan atlet aktif.
- ⚡ **4 Pilar Karakter & Filosofi Tim**: Fundamental Mastery, Tactical Intelligence, Athletic Conditioning, dan Brotherhood.
- 📋 **Kurikulum & Program Pembinaan**: Kelas Dasar/Reguler, Tim Inti (Varsity), dan Sesi Fisik.
- 📅 **Jadwal Latihan Mingguan**: Jadwal sesi latihan rutin di Lapangan Utama SMK Pasundan 2 Banjaran.
- 📸 **Galeri Aksi Nyata Tim**: Grid interaktif dari seluruh 14 foto dokumentasi resmi tim dengan fitur Lightbox Modal.
- 💬 **Kontak & DM Instagram Langsung**: Tombol terintegrasi langsung menuju Direct Message Instagram resmi [@pasundan2basketball](https://www.instagram.com/pasundan2basketball).
- ❓ **FAQ Interaktif**: Jawaban atas pertanyaan-pertanyaan umum siswa & orang tua seputar eskul.
- 📍 **Info Lapangan & Kampus**: Alamat resmi SMK Pasundan 2 Banjaran beserta petunjuk arah Google Maps.

---

## 🚀 Menjalankan Secara Lokal

```bash
# Install dependencies
npm install

# Jalankan server pengembangan
npm run dev

# Buka http://localhost:3000 di browser
```

## 🌐 Deployment ke Vercel

Proyek ini telah dikonfigurasi penuh untuk Vercel:
1. Hubungkan repository GitHub ke akun Vercel.
2. Vercel akan secara otomatis mendeteksi framework **Next.js**.
3. Klik **Deploy**.
